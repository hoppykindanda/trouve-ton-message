# Trouve ton message

Trouve ton message t'interviewe en sept questions, une à la fois, puis transforme ce que tu as vécu en message : ta phrase courte à dire en quelques secondes, ton message complet, et ses fondations.

## Installation : un seul prompt

Ouvre Claude Code et colle ce message :

```
Installe le skill Trouve ton message pour moi : télécharge https://raw.githubusercontent.com/hoppykindanda/trouve-ton-message/main/trouve-ton-message/SKILL.md et enregistre-le dans ~/.claude/skills/trouve-ton-message/SKILL.md (crée le dossier s'il n'existe pas). Vérifie que le fichier est bien là, puis dis-moi « Trouve ton message est installé ».
```

## Utilisation

Dans une nouvelle conversation, écris : **« Trouve mon message. »**
